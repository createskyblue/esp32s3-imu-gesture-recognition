# 原始训练数据集

本目录为模型训练所用的原始数据（三轴加速度，单位 g），与 `gesture_c` 库 `data/` 下的文件相同。

| 文件 | 类别 | 样本数 |
|------|------|--------|
| `gesture_A_6.csv` | A | 50 |
| `gesture_B_6.csv` | B | 50 |
| `gesture_C_6.csv` | C | 52 |

- 每行 = 1 条样本 = 300 个浮点数：100 个采样点 × 3 轴（X/Y/Z 交错），即 `[ax0, ay0, az0, ax1, ay1, az1, ..., ax99, ay99, az99]`。
- 采集参数：QMI8658 加速度计 ±4 g 量程、50 Hz、单条 2 秒；CSV 中数值已换算为 g。
- 总计 152 条；本数据集即 README「开发流程」第 1 步所述训练数据。
